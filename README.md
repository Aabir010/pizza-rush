# Pizza Rush 🍕

A fast-paced browser game built using vanilla HTML5 Canvas and JavaScript.

## How to Play
1. Clone this repository to your local machine.
2. Open `index.html` directly in any web browser, or serve it using a local server extension like **VS Code Live Server**.

## Tech Stack & Architecture
- **Frontend:** HTML5 Canvas, CSS3
- **Logic Engine:** Vanilla JavaScript utilizing a `requestAnimationFrame` game loop.
- **Render Illusion:** Dual-segment scrolling treadmill logic using modulo (`%`) offsets to maintain endless performance stability without resource leaks.
